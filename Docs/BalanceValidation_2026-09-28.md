# 전체 밸런스 검증 — 2026-09-28

> 과거 규칙의 검증 기록입니다. 이후 제한 Drop·누적 파괴, 열별 강화 브릭, 클리어 생존 고양이 골드 정산 및 창고 기획 삭제가 적용됐습니다. 현재 규칙은 `CatMergeDrop_DevelopmentPlan.md`의 최신 결정이 우선하며, 아래 경제 결과를 현행 밸런스 인증에 사용하지 않습니다.

## 범위와 신뢰도

현재 설정·1,000개 스테이지를 읽어 검증했다. 게임 설정과 세이브는 변경하지 않았다. 실제 Unity ECS를 격리 World에서 실행한 98개 사례와 Python 모델의 승패, 일반 골드, 특수 블록 파괴 수, 종료 프레임이 전부 일치했다(프레임 차이 0). 이는 해당 사례의 전투 일치 검증이며 모든 상태나 경제 UI를 실제 Unity로 자동 플레이한 것은 아니다.

소환 가격·확률, 머지 최고 레벨, 실패 보상, 성공 시 출전 고양이 소모, 즉시 티켓 개봉을 연결한 연속 진행 모델을 사용한다. 세 정책×20개 난수 시드를 비교한다. 실제 시작금 30G와 원인 분리를 위한 가정 60G는 분리한다. 후자는 설정 변경이나 추천 수치가 아니다.

## 전체 카탈로그 비교

전력 접근성은 제외하고 생성기의 기준 레벨 `1+floor(log2(stage))` 고양이 세 마리를 각 열에 세로 배치했다. 총 4,333전투, 시간 초과 0건.

| 결과 | 스테이지 수 |
|---|---:|
| 어느 열도 성공하지 못함 | 6 |
| 정확히 한 열만 성공 | 186 |
| 모든 열에서 성공 | 116 |
| 골드를 얻는 실패 열이 존재 | 884 |

통과 열이 없는 곳은 Stage 1·4·6·8·9·14다. 이는 해당 기준 편성의 결과이며 스테이지 자체가 불가능하다는 뜻은 아니다. 자동 생성 기준 레벨과 실제 요구 전력의 연결이 초반부터 검증되지 않았음을 보여 준다.

Stage 43에서 Lv.6 세 마리는 4개 열 중 2개 열을 통과했다. 0부터 세는 열 1의 성공은 일반 270G와 Gold/Item 티켓 각 1개, 열 2의 실패는 일반 360G와 고양이 보존이었다. 성공에는 별도 기본 보너스도 있으므로 단순 골드만으로 손익을 비교하면 안 된다. 다만 실패 후 브릭 복원과 고양이 보존으로 같은 실패를 반복해 골드를 벌 수 있다는 구조는 재현된다. 이 전투의 5.85초는 입력·준비·UI 시간을 제외한 모델 시간이다.

## 연속 진행 결과와 판정

**전체 밸런스 검증 통과로 판정할 수 없다.** 초기 진행 막힘이 있고, 이를 우회한 진단에서도 정책에 따른 극단적인 편차와 실패 파밍 의존이 확인됐다. Stage 43의 낮은 블록 하나만 바꾸어 해결할 범위가 아니다.

| 시작금·정책 | 시드 수 | 완료한 Stage | 종료 이유 |
|---|---:|---:|---|
| 실제 30G·세 정책 | 60 | 모두 0 | 정책 내 진행 수단 소진 |
| 가정 60G·자동 머지·분산 | 20 | 모두 0 | 해당 배치에서 수입 없이 막힘 |
| 가정 60G·자동 머지·집중 | 20 | 844~864, 중앙 856 | 모두 20,000전투 관측 제한 |
| 가정 60G·머지 지연·집중 | 20 | 모두 1 | Stage 2에서 100회 관측 제한 |

실제 30G에서는 20G 소환 후 Lv.1 한 마리와 10G가 남는다. 집중 정책으로 4개 열을 모두 시도해도 일반 골드 수입 0, 성공 0이었다. 소환 레벨이 고정되는 초반이라 이 부분의 20개 시드는 독립적인 확률 차이를 만들지 않는다. 모델에 포함한 기본 루프에서는 추가 소환·머지·실패 수입으로 회복할 수 없다.

가정 60G의 자동 머지·집중 정책은 총 400,000전투 중 성공 17,124회, 실패 382,876회(**95.719%**), 그중 골드를 얻는 실패 382,559회였다. 이는 사람의 실패율이나 최적 전략의 결과가 아니다. 다만 소환·소모·보상을 연결한 실제 규칙하에서 실패 파밍을 크게 반복하는 진행 경로가 재현됐다. 완료된 스테이지의 시도 횟수는 다음과 같다.

| 구간 | 클리어당 평균 시도 | 중앙값 |
|---|---:|---:|
| 1~20 | 3.81 | 4 |
| 21~100 | 8.03 | 8 |
| 101~300 | 16.57 | 17 |
| 301~500 | 22.80 | 23 |
| 501~800 | 32.17 | 34 |

머지 지연 정책은 Stage 2에서 골드가 있어도 자체 머지 조건 때문에 진행하지 못했다. 따라서 이 결과를 자금 부족이나 게임 전체 막힘으로 해석하지 않는다. 분산 정책 역시 배치를 바꾸는 인간까지 막힌다는 증거가 아니다. 반대로 자동 머지·집중 정책의 후반 도달은 정상적인 신규 유저 진행을 증명하지 않는다. 실제 시작금에서는 첫 스테이지를 넘지 못했고, 후반 도달 실험에는 진단용 자금이 추가되었다.

우선 조정 대상은 (1) 초기 전력과 첫 스테이지의 연결, (2) 성공 시 소모 전력과 보상의 회복량, (3) 실패 파밍의 역할·목표 횟수, (4) 보상 열과 쉬운 경로의 반복 결합이다. 목표 진행 템포를 정한 뒤 이 네 항목을 함께 수정하고 같은 실험을 다시 비교해야 한다. 이번에는 검증 도구와 문서만 추가·수정했고 게임 수치는 조정하지 않았다.

## 해석의 한계

정책은 최적 플레이어가 아니다. 집중 정책은 실패 때 열을 순환하며 정답 열을 미리 보지 않는다. 창고 확장·판매·티켓 비축·최적 탐색은 제외했다. 준비 중 소환 한 번의 묶음 이후 머지하고 출전하는 정책이므로 골드를 전부 쓸 때까지 머지와 재소환을 반복하는 플레이와 다르다. 정책 막힘은 게임 전체의 불가능 판정이 아니다. 스테이지당 100회·시드당 20,000전투 제한에 닿으면 관측 중단으로 기록한다. 사람의 승률, 세션 길이, 재미와 리텐션은 측정하지 않았다.
